# 版本记录

> 发版时在顶部追加一条（`## 版本号 — 日期` + 最多 3 行内容），并同步更新服务器上的 `app-version.json`。

## 0.1.5 — 2026-11-15
- 修复视频播两秒卡住：Surface 只在 `AndroidView.factory` 绑定一次，不再随进度回调重组反复重挂。
- 播放/暂停点击即时回写状态，并每 300ms 与播放器对齐，解决需点两三次才生效。
- 新增缓冲转圈、播放失败提示与「重试」，播放器错误写入调试日志。

## 0.1.4 — 2026-11-15
- 修复视频播放页点击播放按钮无反应：改用 `playWhenReady` 驱动播放/暂停，未 prepare 自动 prepare、播完自动回到开头。
- 进度条改为自定义绘制：三层轨道（背景/缓冲/已播）+ 圆形 thumb，拖动时放大，支持点击跳转与拖动 scrub。

## 0.1.3 — 2026-11-15
- 修复 WS 上行缺 `timestamp` 被服务端 1001 拒绝，导致呼叫、接听、已读上行全部失效。
- 心跳帧与直播弹幕帧同步补齐 `timestamp`，避免连接被判定为超时。

## 0.1.2 — 2026-11-15
- 我的页新增「开发调试」：右上角实时日志浮层，结束后可导出到 Downloads。
- 来电改为先振铃再拉 ICE 配置，避免配置请求拖慢响铃；WS/通话信令全部写入调试日志。
- 高级设置版本号只显示版本名，不再带 versionCode。

## 0.1.1 — 2026-11-15
- 高级设置新增「版本号 / 检查更新」，读取 `{服务器}/app-version.json`，按 versionCode 判断是否最新。
- 登录页新增生产 / 测试 / 自定义环境选择，生产默认改为 `https://120.78.126.132`（IP 直连放开自签证书校验）。
- 网络错误按 DNS / 证书 / 连接重置 / 超时分别提示，便于排障。

## 0.1.0 — 2026-11-12
- 首个内测版：登录、会话、聊天、群组、好友、直播、AI、个人中心与设置。
